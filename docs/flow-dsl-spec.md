# Flow DSL reference moved

The public syntax authority is now the shared [Diagram DSL specification](diagram-dsl-spec.md).

It contains the complete `type flow` body grammar, fields, semantic rules,
variant operations, positions, formatting, JSON mapping, diagnostics, and
validation guidance. Flow documents use the `.diagram` extension and begin
with `diagram 1` followed by `type flow`.

The distributed copy is
`skills/author-flow-diagrams/references/flow-dsl-spec.md`. It is byte-identical
to the shared specification. This file remains as a stable repository path for
older links; it is not a second syntax reference.
